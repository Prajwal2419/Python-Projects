# Python Projects

A collection of beginner-friendly Python programs and games.

## Included Projects

### 1. Basic Calculator (`Basic Calculator.py`)
A command-line calculator that performs basic arithmetic operations like addition, subtraction, multiplication, and division.

### 2. Hangman Game (`Hangman_game.py`)
A word-guessing game in the terminal centered around animals. Players try to guess the hidden animal name before running out of attempts.

## How to Run

1. Make sure you have **Python 3** installed.
2. Clone or download this repository.
3. Open a terminal in the project folder and run:

```bash
# To run the calculator:
python "Basic Calculator.py"

# To play hangman:
python Hangman_game.py
